                  PETUNJUK APLIKASI ASISTEN PAYROL
====================================================================

Aplikasi Asisten Payrol memiliki 2 modul utama:
1. Merge Data Lembur (Excel & PDF OCR AI)
2. Checker Reimburse (Rekonsiliasi Form Rekap vs Kwitansi Lampiran)

--------------------------------------------------------------------
1. CARA MENJALANKAN:
--------------------------------------------------------------------
- Double click / buka file "Jalankan Aplikasi.bat" atau "MergeLembur.exe"
- Browser akan otomatis terbuka menuju halaman web aplikasi.

--------------------------------------------------------------------
3. CARA PENGGUNAAN:
--------------------------------------------------------------------
  A. MODUL MERGE DATA LEMBUR (Tab "📊 Merge Data Lembur"):
     - Drag & Drop file Excel (.xlsx) atau PDF SPL lembur (Multiple).
     - Data lembur otomatis diproses & digabungkan dengan AI.
     - Klik "Download Hasil Gabungan" untuk mengunduh Excel gabungan.

  B. MODUL CHECKER REIMBURSE (Tab "🧾 Checker Reimburse"):
     - Drag & Drop file PDF klaim reimburse karyawan (form rekap + lampiran nota).
     - AI Vision otomatis membaca total rekap pengajuan & seluruh nota fisik.
     - Sistem langsung membandingkan nominal dan menampilkan status:
       * 🟢 COCOK (MATCH): Total rekap = Total kwitansi fisik.
       * 🔴 SELISIH: Menampilkan rincian nominal selisih lebih/kurang klaim.
     - Klik "Download Laporan Audit Excel" untuk mengunduh laporan audit resmi.

- Aplikasi 100% standalone (tidak perlu instal Go/Python/Excel).
- Jangan tutup jendela hitam (console) saat aplikasi sedang digunakan.
- Untuk menutup aplikasi, cukup tutup jendela console atau tekan Ctrl+C.
